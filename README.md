# R&R-rar

R&R-rar is a Linux desktop app for quiet time with books, music, and games. It keeps an offline books library, including the KJV Bible and public-domain classics, read aloud in a natural narrator voice with an audio visualiser. A music player sits alongside the library, and the games include Hearthblock, Riftfront, Hive Siege, Scribble Swap, Flag Frenzy, and Noodle Rush.

Switch between Online and Offline mode whenever you like. R&R-rar is built on Holochain and packaged as an Electron app.

## Download

The latest build is on the [GitHub release](https://github.com/Russell117/rr-rar/releases/latest):

- [rr-rar.deb](https://github.com/Russell117/rr-rar/releases/latest/download/rr-rar.deb) — Ubuntu and Debian
- [rr-rar.AppImage](https://github.com/Russell117/rr-rar/releases/latest/download/rr-rar.AppImage) — portable Linux build

### Ubuntu / Debian

```bash
sudo apt install ./rr-rar.deb
```

### AppImage

```bash
chmod +x rr-rar.AppImage && ./rr-rar.AppImage
```
